# DABA Workshop - Large Language Models, Prompt Engineering & Agentic AI

## 📚 Workshop Overview

This workshop provided hands-on learning experience in Large Language Models (LLMs), Prompt Engineering, Hugging Face, Reasoning, and Agentic AI.

The workshop covered the fundamentals of how Large Language Models process text and generate responses, along with practical activities using AI tools and models.

---

## 📖 Topics Covered

### 1. Setup

Learned how to set up the required environment for working with Large Language Models and AI tools.

The setup included configuring the development environment, installing required libraries, and preparing the workspace for practical exercises.

---

### 2. Parts of a Prompt

Learned the basic components of a prompt and how different instructions affect the response generated by an AI model.

The main concepts included:

- System instructions
- User instructions
- Context
- Examples
- Expected output

---

### 3. Tokens

Learned how text is divided into smaller units called tokens.

Tokens are the basic units processed by Large Language Models.

Topics included:

- Tokenization
- Input tokens
- Output tokens
- Token limits
- Relationship between text and tokens

---

### 4. Tokens to Embeddings

Learned how tokens are converted into numerical representations called embeddings.

Embeddings represent text in a form that machine learning models can process.

Basic flow:

Text → Tokens → Embeddings

---

### 5. Embeddings to Attention

Learned the basic concept of how embeddings are processed using the attention mechanism.

Attention helps the model understand the relationship between different words or tokens in a sequence.

Basic flow:

Tokens → Embeddings → Attention → Contextual Representation

---

### 6. Prediction

Learned how Large Language Models predict the next token based on the given input and context.

The prediction process helps the model generate responses one token at a time.

Basic flow:

Input → Model Processing → Next Token Prediction → Generated Response

---

### 7. Streaming

Learned how AI models can generate and display responses continuously instead of waiting for the complete response.

Streaming provides a more interactive experience because the generated text appears progressively.

---

### 8. CoT and Reasoning

Learned about Chain-of-Thought (CoT) and reasoning concepts used for solving complex tasks.

The workshop introduced how structured reasoning can help models handle multi-step problems.

---

### 9. Hugging Face

Learned how to use Hugging Face tools and models for working with Large Language Models.

The practical activities included:

- Hugging Face account setup
- Authentication
- Model access
- Tokenizers
- Loading AI models
- Text generation

---

### 10. CTF

Participated in a Capture The Flag (CTF) activity related to prompt injection and AI security concepts.

The activity included multiple levels where the objective was to understand the provided CTF environment and solve the challenges.

The activity helped demonstrate the importance of prompt instructions, model behavior, and secure handling of sensitive information.

---

### 11. AI Town

Explored the concept of AI Town and how multiple AI-based agents can interact within a simulated environment.

The activity introduced concepts related to:

- AI agents
- Agent interactions
- Simulated environments
- Autonomous behavior
- Agentic AI

---
