# Day 11 Dataset

This folder contains the dataset-related files used for the Day 11 Policy Conflict Detection and Explainable Decision module.

## Purpose

The dataset is used to test:

- Policy conflict detection
- Return validation
- Risk analysis
- Policy evidence retrieval
- Explainable AI decisions

## Dataset Source

The return dataset was created as part of the project using Python and contains synthetic customer return records.
